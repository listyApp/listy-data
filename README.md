# listy-data

Price data for the Listy shopping-list app, published on GitHub Pages at
https://listyapp.github.io/listy-data/.

Everything here is built from the files Israeli supermarket chains publish under
the price-transparency law (חוק קידום התחרות בענף המזון — שקיפות מחירים), by the
`prices` workflow, every three hours. The data lives on the `gh-pages` branch and
is replaced on each run.
